# Capturas públicas

`painel.jpg` apresenta o painel do Trilha Viva com conteúdo fictício. A imagem documenta a interface, não a execução de serviços externos, e não garante que o mesmo commit já esteja publicado.

Ao atualizar capturas, use apenas dados demonstrativos, remova informações de conta, credenciais, mensagens privadas e documentos pessoais. Preserve dimensões legíveis e texto alternativo no README. Não inclua referências ou pranchas locais não destinadas à publicação.
