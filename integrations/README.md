# Integrações e comparações

Estas pastas oferecem preparação reproduzível, não prova de que ferramentas externas foram usadas.

- [`n8n/`](n8n/README.md): template inativo e configuração do fluxo principal opcional.
- [`examples/`](examples/README.md): eventos fictícios para testar uma pequena etapa comparável.
- [Guia completo](../docs/integracoes.md): Make/Zapier como alternativas, v0/Bolt para propostas e Cursor para apoio de desenvolvimento.

O produto principal não precisa acionar todas as ferramentas ao mesmo tempo. Nunca ative automações de mensagens ou serviços pagos sem configuração e autorização. Exporte fluxos sem credenciais, identificadores sensíveis ou dados privados. Nenhuma instância de n8n, Make ou Zapier foi autenticada/executada nesta implementação.
