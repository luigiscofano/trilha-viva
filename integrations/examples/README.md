# Exemplos de eventos

`completed-task.json` é um payload fictício para explorar uma etapa de automação de tarefa concluída. Não contém dados de usuário ou credenciais e não representa uma execução real.

Use o mesmo evento de teste para comparar n8n, Make e Zapier, sem ativar três fluxos redundantes no produto principal. Não configure mensagens, e-mails ou notificações sem autorização do destinatário/responsável. Veja [guia de integrações](../../docs/integracoes.md).
